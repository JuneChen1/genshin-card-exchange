# <img src="public/favicon-32x32.png" width="28" height="28" alt=""> 月諭聖牌交換站 Luna Card Exchange

一個專為《原神》玩家打造的月諭聖牌（Luna Rite Cards）登記與交換媒合平台。

玩家只要註冊一個網站帳號，就能同時管理本帳、小帳等多個原神 UID 底下的聖牌「多餘 / 缺少」狀態，並透過自動比對，快速找到能互相交換卡牌的好友。

---

## 這是什麼？

原神的月諭聖牌需要玩家之間互相交換才能集滿圖鑑，但要在茫茫玩家中找到「剛好你缺的牌我有、我缺的牌你有」的對象並不容易。

月諭聖牌交換站讓你：

- 為每個原神 UID 分別登記「多餘可換」與「缺少徵求」的聖牌
- 一鍵搜尋全站玩家，找出雙向都能互補的交換對象
- 依伺服器（Europe / America / Asia / TW,HK,MO）篩選，避免找到跨服無法交易的對象
- 選填聯絡方式（Discord、X 等），只有你自己決定要不要公開

---

## 主要功能

- **會員系統**：註冊 / 登入 / 登出
- **多 UID 管理**：可新增多個原神 UID，各自獨立設定卡牌狀態
- **聖牌狀態設定**：每張聖牌可標記為「未設定」「多餘」「缺少」三種狀態之一
- **交換媒合搜尋**：不需登入即可用「我想要的牌」「我多出的牌」「伺服器」搜尋可交換對象，也可以完全不篩選、瀏覽全站所有玩家的多餘 / 缺少清單
- **可選擇的伺服器**：Europe / America / Asia / TW, HK, MO

## 網站怎麼使用

### 1. 註冊帳號
點右上角「註冊」，輸入帳號、密碼（需再輸入一次確認密碼）即可完成註冊。

### 2. 新增原神 UID
登入後進入「個人頁面」，在「新增原神 UID」欄位輸入你的原神 UID（本帳或小帳都可以新增多筆）。

### 3. 設定聖牌狀態
點選列表中的某個 UID，進入該 UID 的聖牌圖鑑頁面，針對每張聖牌選擇：

- **未設定**：你沒有多餘也不缺少
- **多餘**：你有多的，願意換出
- **缺少**：你正在徵求這張

設定完成後按「儲存變更」。

### 4. 搜尋交換對象
回到首頁，展開「尋找交換對象」，選擇：

- **我想要的牌**：找有這些牌可以換給你的人
- **我多出的牌**：找正在徵求這些牌的人
- **伺服器**：可選擇 Europe / America / Asia / TW,HK,MO，不選則不限伺服器

三個條件都可以任意組合，搜尋結果會顯示對方的 UID、可交換的卡牌，以及對方選填公開的聯絡方式（若對方沒填寫聯絡方式，則不會顯示）。

### 5. 編輯個人資料
點右上角帳號選單的「編輯個人資料」，可修改：
+ Email（選填，用於忘記密碼時找回帳號）
+ 聯絡方式（選填，填寫後才會出現在交換搜尋結果中），

也可以在這裡修改密碼。

## 專案架構

- **前端**：HTML5、Vanilla JavaScript（ES6+）、Bootstrap 5
- **後端**：Node.js、Express.js（RESTful API）
- **資料庫**：PostgreSQL（透過 TypeORM 存取）
- **認證**：JWT 認證
